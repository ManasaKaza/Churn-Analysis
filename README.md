# Customer Churn Analysis & Prediction

This project analyzes customer churn patterns and builds a machine learning model to predict whether a customer is likely to churn. It includes data preprocessing, feature encoding, Random Forest classification, prediction generation, and Power BI-based visualization.

## Tech Stack
Python, pandas, NumPy, scikit-learn, matplotlib, seaborn, Power BI

## Features
- Cleaned and prepared customer churn data
- Encoded categorical features using LabelEncoder
- Trained a Random Forest classification model
- Evaluated model performance using classification metrics and confusion matrix
- Generated prediction outputs for analysis
- Built a Power BI dashboard for churn insights and customer segmentation

## Project Files
- ChurnAnalysis.ipynb — ML workflow and prediction pipeline
- PredictionData.xlsx — input dataset
- C__Predictions.csv — generated predictions
- Churn Analysis.pbix — Power BI dashboard
